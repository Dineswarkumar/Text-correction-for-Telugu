## Key Takeaways from Baseline Evaluation:
1. **Rule-Based Corrector** quickly resolves high-frequency matra length and consonant confusions with zero false positives on known dictionary words.
2. **Dictionary + Edit Distance** achieves significant WER reduction for single-character typos and deletions within edit distance <= 2.
3. **Hybrid Approach** combines deterministic phonetic rules with statistical edit-distance fallback, providing the strongest pre-neural baseline.
4. **Remaining Challenges for Neural Models (IndicBART / mT5):** Multi-character deletions, space merging (sandhi), and real-word contextual errors require deep contextual Seq2Seq transformers.
